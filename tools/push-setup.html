Push key setup

This page generates keys locally on your iPhone using Web Crypto. It makes no network requests and does not save or upload the results. Use Safari on your own device.

Generate once. Copy the values directly into Supabase Edge Function Secrets (and the dispatch secret into Vault). Keep a secure backup in your password manager. Do not paste secrets into GitHub, chat, screenshots or public files.

Set VAPID_SUBJECT to mailto:YOUR_REAL_EMAIL_ADDRESS. A valid monitored email is required; do not use a localhost URL. Leave PUSH_DELIVERY_ENABLED set to false until manual tests pass.
